# Veeduría Caucasia — Obras y parques al día

App ciudadana (PWA) de Vibras Positivas HM para hacer veeduría a los parques y obras de Caucasia, Antioquia. Empieza por el Parque El Palmar.

- App: https://veeduria-obras-caucasia.netlify.app/
- Robot (GitHub Actions) cada 30 minutos: noticias reales y contratos de obra de Caucasia en el SECOP II.
- Para agregar o corregir una obra: edite `data/obras.json`.

No es una página oficial de la Alcaldía de Caucasia.
